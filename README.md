# css-popup-modal-target
A lightweight, fully responsive popup modal component built with pure HTML5 and CSS3 using the :target pseudo-class—without using JavaScript.

## 🛠️ Built With

* **Markup:** [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) (Semantic elements, `<a>`, `<div>`, `<h2>`, `<p>`)
* **Styling:** [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) (CSS `:target` pseudo-class, Flexbox, Gradients)
